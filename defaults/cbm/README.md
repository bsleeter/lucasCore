# CBM-CFS3 default tables

Copied unchanged from the ApexRMS lucasbuilder 2.0.4 package (`data/`), which takes them from the CBM-CFS3 archive index defaults
(Natural Resources Canada). lucasCore uses:

- The turnover, decay and transfer tables: for stage 3.

The Boudewyn stemwood tables and `species-crosswalk.csv` are no longer used (2026-10-20): stage 2 converts merchantable volume
to carbon with US wood and bark densities (`defaults/growth/merch-carbon-density.csv`, from FIA REF_SPECIES and EVALIDator).
